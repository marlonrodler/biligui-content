# lero-content

Conteúdo público do app **Lero** (áudios, imagens e manifestos dos pacotes), servido pelo GitHub Pages:
`https://marlonrodler.github.io/lero-content/`

Gerado automaticamente pelo pipeline do repositório `lero`. Não edite à mão.

## Estrutura
```
packs/index.json                lista de pacotes e versões publicadas
packs/<pacote>/<versão>/        manifest.json, audio/, img/
packs/<pacote>/draft/           rascunho para revisão no admin
```
